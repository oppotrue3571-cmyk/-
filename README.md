# สัดส่วนใบหน้า

เว็บหน้าเดียว (`index.html` ไฟล์เดียว ไม่มี build) เปิดกล้อง → กดถ่าย → ตัวนับ 0–100% → ได้สรุปและค่าวัด ประมวลผลในเบราว์เซอร์ รูปไม่ถูกเก็บหรือส่งออก

## สิ่งที่ทำ

- ถ่าย 8 เฟรมในราว 1.8 วินาที แล้วใช้ค่ากลาง (median) ของจุดบนใบหน้า ผลนิ่งกว่าเฟรมเดียว
- สรุปเป็นประโยค เช่น "หน้าผากยาวกว่าส่วนอื่น" พร้อมระดับ (เล็กน้อย / ค่อนข้างชัด / ชัดเจน) และตัวเลข
- ค่าวัด 4 กลุ่ม: สามส่วนแนวตั้ง, ห้าส่วนแนวนอน, ดัชนีใบหน้า, ความสมมาตร แต่ละค่ามีสเกลเทียบช่วงอ้างอิง
- แถบ "ไรผม": โมเดลไม่เห็นไรผมจริง ต้องเลื่อนให้เส้นสีเขียวอ่อนตรงไรผมก่อน ผลหน้าผากขึ้นกับจุดนี้
- แสดงความนิ่งระหว่างเฟรม (±จุด %) และเตือนเมื่อหน้าหันเฉียง
- ข้อความผิดพลาดที่ชัด: ไม่อนุญาตกล้อง, ไม่พบกล้อง, กล้องถูกใช้อยู่, โหลดโมเดลไม่สำเร็จ (มีปุ่มลองใหม่)
- ปิดกล้องอัตโนมัติหลังถ่ายและเมื่อสลับแท็บ

## รันในเครื่อง

กล้องต้องใช้ https หรือ localhost:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## Deploy ด้วย GitHub Pages

Push `index.html` → Settings → Pages → Branch: `main` / `(root)` → ได้ลิงก์ `https://<user>.github.io/<repo>/`

## ข้อจำกัด

- ต้องหน้าตรง แสงสม่ำเสมอ ไม่ใส่แว่น ผมไม่บังหน้า ปากปิด ไม่เงย/ก้ม
- ไรผมเป็นค่าประมาณจนกว่าจะเลื่อนแถบเอง
- ห้าส่วนใช้ขอบแก้มแทนหู ส่วนนอกจึงมักต่ำกว่า 20%
- ดัชนีใบหน้าจากจุดบนภาพคลาดเคลื่อนง่าย สรุปจะรายงานเมื่อเบี่ยงจากช่วงกลาง (84–88) เกิน 6 เท่านั้น
- เป็นการเทียบตัวเลขกับค่าอ้างอิงเชิงเรขาคณิต ไม่ใช่คะแนนความสวยหรือการวินิจฉัยทางการแพทย์
- ทดสอบด้วยโมเดลจำลองและกล้องปลอมใน Chromium (ลำดับถ่าย → สแกน → สรุป → ปรับไรผม → ถ่ายใหม่ ไม่มี error) แต่ยังไม่ได้ลองกับโมเดลจริงและใบหน้าจริง
